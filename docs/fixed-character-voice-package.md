# 固定角色声线包接入约定

本轮只预装读取与校验能力，电脑版和安卓版均没有开启入口，继续播放现有音频。角色音量仍可调整；不提供玩家自由换音色。新声线的生成、回读与听验需等角色配音包完成后单独接入。

未来每章可附加 `character-voices/fixed-voices.json`，不改变原节点编号和路线。清单为 schemaVersion=1，包含 packId、navigationFingerprint 及 lines。每条记录包含 nodeId、原 speaker、固定 voiceId、正文 UTF-8 SHA256（小写）和相对清单目录的 audio。一个 speaker 在同一清单中只能有一个 voiceId；匿名标签和待核身份不自动归并为其他人物。

加载时核对配音包、导航版本、节点身份、角色、原文哈希、重复编号、相对路径边界及音频存在性。清单不能携带开启指令；缺失或损坏时继续原配音。后续明确接入时由程序调用 FixedVoices.SetEnabled(true)，不向玩家提供声线候选。清单加载、重载均默认关闭。

开启后的录音时长变化必须使听书时长缓存失效。软件级通过只证明接入与回退逻辑，不证明新声音已生成或完成听审。
