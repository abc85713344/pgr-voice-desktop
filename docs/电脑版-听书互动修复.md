# 听书互动续播修复

版本：2026.9.30.4，2026年9月30日。互动续播已支持三种听书策略，见[听书策略修复](电脑版-听书策略修复.md)。

## 修复了什么

第一章第一节播放到露西亚“必须阻止它们！”后，旧版把“等待游戏交互”当成当前小节的终点，导致后面的台词没有展开。录音与正文仍在配音包里。

新版在配音包明确登记了续接菜单时，按所选策略展开互动：“手动选择”显示选项并等待确认；“默认第一项”自动进入首个可用选项；“全部听取”依次播放各选项。普通剧情分支使用相同策略。

## 怎样继续第一章第一节

1. 正常退出旧播放器，再通过原桌面入口启动新版。
2. 打开“听书”，选择第一章、第一节。若之前已经跳到下一节，请选第一节并点“定位到小节开头”；也可在台词列表中定位“必须阻止它们！”。定位后保持暂停。
3. 在“收听选项与书签”中选择支线策略，再点击“播放 / 续听”。手动策略会在互动处显示“等待互动”和选项，自动策略直接继续。
4. 手动策略下点击“（与地上的构造体互动）”；自动策略下无须点击。随后会播放里“很遗憾，他……刚刚失去了意识活动……”和露西亚“前方还有幸存者！”，之后继续“最后两只了！”及后文。
5. 本节后面还有普通选择，按当前策略选择或继续即可。

滚动、浏览和停在手动互动界面不会播放。手动策略下，确认选项才开始该段；“下一句”不会绕过待选互动。若有多个续接菜单，手动策略先选菜单再选选项；自动策略按所选方式展开。

“全部听取”依次自动收听菜单中的互动选项，再继续共同后文；已有明确互动连接的正文不会作为散落的“补充片段”播放。此模式包含互斥路线，是资料收听顺序。完整正文目录仍允许浏览尚未收听的内容。

## 进度与范围

- 互动等待、所选路线和句内位置保存在独立听书进度中。重开保持暂停。
- 旧自动策略断点停在互动菜单时，恢复到该互动展开后的台词并保持静音，点击播放才继续。手动策略仍保留待选状态。
- 已明确跳到其他小节的旧断点仍会保留。需要补听第一节时按上述步骤返回。
- 修复适用于有明确续接菜单的其他章节；没有可靠连接的内容仍保留原来的核对限制，不按音频编号猜后文。
- 本轮更新电脑版播放器，不更改原录音、台词编号、配音包核对状态或游戏模式的分支条件。

听书按菜单中已经登记的连接展开后文，不表示对应游戏出口已完成核实。
