# 电脑版听书与图标更新

版本：2026.9.30.1。

## 选章后直接查看台词

此前在听书页选了第18章，下方仍可能保留第40章的正文，因为还需要点「打开所选大章」。新版将章节选择与内容加载连在一起：选择大章后，目录、台词和当前收听信息同步切换，保持暂停。

1. 打开「听书」页，在顶部选择大章。配音包只含一个大章时，仅显示一个章节选择框；含多个大章时，再选择包内章节。
2. 在小节下拉框中选择要查看的小节，下面直接显示可滚动的台词列表。
3. 浏览、选中或滚动台词不会触发新录音。需要从某句开始时，选中它，点「定位到选中台词」，再点「播放 / 续听」。
4. 想从小节开头开始，点「定位到小节开头」，再主动播放。想找回当前收听位置，点「回到正在听的句子」。

2026.9.30.3起，目录列出本小节全部已收录正文，包括未选择的支线及互动后文。播放资格与浏览分开：待选内容标注提示，定位时先静音打开本节待选菜单，确认后才开始收听。完整用法见[听书完整正文](电脑版-听书完整正文.md)。

台词列表使用独立滚动区域，播放按钮保留在下方。当前长台词也可单独滚动查看。支线策略、恢复上回章节和书签移到默认收起的「收听选项与书签」，需要时点击标题展开。

## 暂停与进度

- 选章、定位和恢复书签均保持暂停，点击「播放 / 续听」才发声。
- 切章前先暂停并保存原章断点。保存失败时，保留原章、当前位置和提示，并把下拉框恢复为原章，避免选章与正文不一致。
- 每个包、每章的听书断点独立保存，包含句内位置；返回听过的章时可从保存的位置继续。
- 听书进度与游戏配音进度分开。听书选路线、定位或恢复书签不会修改游戏中的配音位置与履历。
- 「收听选项与书签」中的「恢复上回章节」和「从当前游戏章开始听」仍可使用，打开后都需主动播放。

完整支线策略、缺音提示、快捷键和自动播放说明见[电脑版-自动播放与听书](电脑版-自动播放与听书.md)。

## 新的软件图标

电脑版采用灰鸦羽翼与声波组成的新图标，以深色底、米白轮廓和红色点缀呼应播放器界面。图标提供多个尺寸，用于程序文件和 Windows 快捷方式等位置。

如果更新后旧快捷方式仍显示原图标，先退出播放器，再从更新目录重新打开；必要时重新创建指向新版程序的快捷方式。图标变化不影响配音包和保存的进度。
