# 听书完整正文显示

版本：2026.9.30.4。

听书小节目录现在显示整节已收录的正文，不会在未选择的互动处截断文本。

第一章第一节“普通 · 1-1灰鸦过境”显示 **100条完整正文及动作提示**。向下滚动可以看到“必须阻止它们！”之后的全部对白，包括“很遗憾，他……刚刚失去了意识活动……”“最后两只了！”和末尾“在那之前，还有一件事……”。其中7条动作提示本来就不朗读，不计为缺少配音。

## 查看与收听

1. 重新打开本机播放器，进入“听书”，选择第一章和“普通 · 1-1灰鸦过境”。目录上方应显示“本小节完整正文100条（含动作提示）”。
2. 直接向下滚动查看后文。尚未在当前收听路线展开的正文会标注“待选择后收听”或“未接入当前收听路线”。浏览、选中和滚动均不播放。
3. 手动策略下，若要收听互动后的部分，点击“打开本节待选互动”，或者选中后文后点击“打开后续剧情的选项”。软件先暂停并打开本节待选菜单，不必从本节开头重播；确认具体选项后才播放。
4. “默认第一项”和“全部听取”会自动展开互动，无须逐处确认。可以定位已经展开的后文，主动播放后按相应策略继续。没有明确续接菜单的未接入正文只能阅读，不能通过定位绕过路线限制；需要收听各条收录路线可明确切换“全部听取”。策略与旧断点说明见[听书策略修复](电脑版-听书策略修复.md)。

完整目录按台本出现顺序显示，含不同选项的正文；实际播放仍按选定路线进行。

## 浏览位置与收听位置

浏览其他小节不会改动已经保存的收听断点。若当前听到1-2、目录切到1-1，会同时显示“正在浏览1-1”和“收听仍在1-2”。下方当前台词前有“收听位置”说明。

点“定位到选中台词”才移动收听位置，并保持暂停；手动策略遇到待选正文时先打开菜单。保存进度失败时不移动原位置。旧进度、原音频、章节编号和游戏模式的路线数据继续保留。
