# 内置剧情与配音绑定（2026-10-12）

播放器加载已收录章节时，使用内置剧情和路线，将导入包中的声音按稳定句子编号及文本版本绑定。原 pack.json、音频和已发布 revision 均不改写。内置基线来自 138 包正式库；其中仍待核的路线保留原边界，不代表全部路线已考证完成。

## 文本版本

每个 line 的 textVersion 为以下 UTF-8 字符串的 SHA256，小写十六进制：

```
pgr-spoken-text-v1\n章节ID\n句子ID\n说话人\n正文
```

这里的 `\n` 是实际换行。正文和说话人不做模糊归一，声音生产使用的读法派生仍需通过原有审核，不能用这个哈希替代听审。

新音入包时把该录音实际生成、审核对应的冻结稿版本写到 audioTextVersion。不要从当前播放器的文字反填版本来给旧录音补标签。textVersion 说明字幕身份，audioTextVersion 说明录音身份，二者不能混用。

旧包没有版本字段时，从该包保存的原正文和角色推导录音版本。只有实际已登记的旧包，才能沿用正式改动记录中明确保留同一录音的兼容关系。ch19、ch33 明确停用的旧录音另外绑定原音频哈希，不能通过改文件名或补版本标签再次启用。

## 新旧包

- 正文及录音版本对应：采用用户导入的音频路径，软件不自带新声音。
- 正文旧、声音缺失或版本不匹配：显示“待补配”，沿用当前字幕停留后继续的行为。
- 只有路线变化：相同正文的声音继续使用。
- 出现未知的新句子、未知正文版本或明确更新的 storyRevision：保留整个原包，提示核对软件更新，不丢弃更新的内容。
- 软件未收录的章节：保留原加载方式。

storyRevision 是内置剧情版本身份，不是 APK 版本号。原包中的音频审核状态、生成记录及真正的声音质量仍由生产和审核流程负责。机器匹配不等于人耳审核通过。

## 更新与进度

本版没有新音发布，不能把“待补配”误报为“已有新音可下载”。补音包正式发布后，再提供对应章节的发布清单和下载入口。当前只交付内置剧情、旧包兼容、逐句版本绑定及待补配提示。

沿用原进度校验，不把所有旧路线选择强行标为兼容。准确可恢复的位置继续恢复，需要重选时按现有界面确认；不删除旧存档。

## 验证

独立检查覆盖历史与现行包的完整正文/图指纹、重复加载、新旧版本绑定、已停用旧波形、未来版本保留，以及真实 PackageRepository 的导入/覆盖导入和原文件不变。声音使用隔离合成 WAV 只验证绑定机制，不冒充真实声音审核或游戏真机通关。
