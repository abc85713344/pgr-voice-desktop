# 听书互动自动续播

版本：2026.9.30.4，2026年9月30日。

听书中的“等待游戏互动”现在遵循已选的收听策略。“默认第一项”和“全部听取”不会再要求逐次点击互动按钮。

## 三种收听方式

在“听书 → 收听选项与书签 → 遇到支线”中选择：

| 策略 | 普通分支与互动处的行为 |
|---|---|
| 手动选择 | 暂停，显示选项；确认后播放对应段落 |
| 默认第一项 | 自动进入菜单中的首个可用选项，播完继续后文 |
| 全部听取 | 按菜单顺序依次播放各选项，再继续共同后文 |

例如第一章第三节的“（与丽芙互动）”，选“默认第一项”或“全部听取”后，连播到这里会直接开始丽芙的对白。第一章第一节“必须阻止它们！”之后的“（与地上的构造体互动）”也使用同一规则。

只有手动策略需要点击选项。全部听取包含互斥及条件路线，是资料收听顺序，不表示游戏中同时经历了所有选择。共同后文只播放一次，未接入正常导航的补充片段仍单独标注。

## 从旧版等待位置继续

1. 关闭旧播放器，再用原桌面入口打开新版。
2. 打开“听书”，恢复原章节。旧版在自动策略下留下的互动待选断点，会接回该互动展开后的台词，保持静音。
3. 确认“遇到支线”为“默认第一项”或“全部听取”，点“播放 / 续听”。后续互动将按该策略继续。

修改策略只更新收听路线和位置，并保持暂停；需要点击播放才开始发声。手动待选处切为自动策略时，会优先保留当前互动位置，不必倒回小节开头。若修改之前的路线导致原位置不再可达，会回到该小节开头。

## 正文与进度

小节目录继续显示完整正文。浏览、选中和滚动不播放；定位台词后保持暂停。听书断点和书签仍独立保存，重启不会自动发声。

本次只调整电脑版听书策略，不修改原始录音、配音包节点、游戏剧情进度或游戏模式的分支核对规则。只有配音包明确登记的互动菜单和正文连接可以据此展开；不会按文件编号猜测未知后文。
