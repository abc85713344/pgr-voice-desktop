# 电脑版：角色头像与立绘（本机图片）

程序和仓库**不包含任何角色图片**。头像与立绘只从你电脑上的文件夹读取，不会上传。

## 放在哪里

未在设置中指定文件夹时，按以下顺序查找（靠前的优先，同名文件只取第一个）：

1. 设置 → 角色头像与立绘 → 「选择文件夹…」指定的文件夹
2. 配音总目录**内**的 `角色头像`
3. 配音总目录**旁**（同一上级目录）的 `角色头像`
   例：总目录为 `D:\配音总目录\全部配音` 时，查找 `D:\配音总目录\角色头像`
4. `%AppData%\PgrVoice\角色头像`

配音总目录取当前打开的章节总目录；只打开单章时，由配音包位置向上推断。

## 文件名

- 文件名 = 台词中的说话人名字（去掉 `\ / : * ? " < > |` 等不能用于文件名的字符），例如 `丽芙.png`。
- 支持 `.png`、`.jpg`、`.jpeg`、`.webp`；同名时按此顺序优先。WebP 需要系统已安装 WebP 解码器，读取失败时显示字标。
- 找不到完整名字时依次尝试：去掉括号注释（如 `露西亚（回忆）` → `露西亚`），再取「·」前的部分（如 `丽芙·极昼` → `丽芙`）。
- 立绘放在同一文件夹下的 `立绘` 子文件夹，文件名规则相同。
- 可选 `aliases.json`（与图片同一文件夹），把别名指向文件名：

```json
{
  // 台词中的名字 : 图片文件名（扩展名可省略）
  "Commandant": "指挥官",
  "露娜（伪装）": "露娜"
}
```

## 显示与开关

- 没有图片时显示名字首字（旁白显示「旁」）。
- 设置 → 角色与封面：显示说话人头像、显示立绘、立绘透明度（0–80%）、选择 / 打开文件夹、重新扫描、恢复默认、减少动画。
- 文件夹内容变化后会自动重新扫描；也可点「重新扫描」。
- 图片在后台按显示尺寸解码并缓存，不会阻塞播放。

## 章节封面

标题区可显示本章封面（横幅），找不到封面时使用默认冷灰白标题样式。封面同样只从本机读取，不随程序发布、不提交到仓库。

- 文件夹名为「章节封面」，查找顺序与头像相同：设置里指定的文件夹 → 配音总目录内 → 配音总目录旁（如 `D:\配音总目录\章节封面`）→ `%AppData%\PgrVoice\章节封面`。
- 支持 png / jpg / jpeg / webp；后台按标题区尺寸解码并缓存，文件夹变化后自动重新扫描。
- 文件名匹配顺序（先找到先用）：
  1. 小节封面：`章节名/小节名.png`（以章节名命名的子文件夹）或 `章节名 小节名.png`；
  2. 完整章节名，例如 `01 涂鸦艺术.png`；
  3. 配音包文件夹名或其 `_` 之前的部分，例如 `主线第01章_MAIN01` → `主线第01章.png`；
  4. 分类 + 编号：`主线第35章_覆海归途.png` → `主线第35章.png`、`外篇EX00.png`、`间章_青鸟.png`、`主线序章.png`；
  5. 章节名、章节编号（`01`、`1`、`第1章`），最后是章节 id（如 `MAIN01`）。
- 同一文件夹的 `aliases.json` 可把以上任一名称指向文件名，例如 `{ "01 涂鸦艺术": "主线第01章" }`。
- 设置 → 角色与封面 →「在标题区显示章节封面」可关闭封面。
