# 第三方组件与素材来源

- .NET / WPF：随程序提供Windows x64运行环境。许可和第三方声明位于 `licenses/DotNet`。项目：https://github.com/dotnet/runtime 、https://github.com/dotnet/wpf 。
- NAudio 2.2.1：音频播放。许可位于 `licenses/NAudio/license.txt`。项目：https://github.com/naudio/NAudio 。
- SDL3：程序随附 `SDL3.dll`。许可和来源记录位于 `licenses/SDL3-LICENSE.txt` 与 `licenses/SDL3-source.json`。项目：https://github.com/libsdl-org/SDL 。
- 可选OCR独立交付：RapidOCR、ONNX Runtime CPU和中文PP-OCRv5 mobile模型；安装组件后，模型来源与校验值位于 `ocr/models/manifest.json`，许可位于 `ocr/licenses` 及 `ocr/_internal`。
- 主题插画与内置游戏美术来自《战双帕弥什》公开游戏素材。主题插画来源记录位于 `Assets/artwork-source.json`；可在设置中关闭主题插画。
- 剧情文本及章节配音独立提供，来源记录随各章节保留。
