# 独立听书核心回归

工程只引用 `core/PgrVoice.Core.csproj`，不依赖安卓、OCR、音频设备或游戏。测试源使用 `.cs.txt`，生成目录位于 `scratch`，避免进入现有核心测试工程的源码通配。

```powershell
dotnet run --project tests\ListeningTests\ListeningTests.csproj
```

命令后追加 `-- <pack.json> ...` 可用真实配音包验证三种策略。真实包只读；不加载或修改游戏存档，不实际播放音频。每章检查：能够结束、节点不重复、手动选择有限、完结快照可恢复、全部收听覆盖所有非归档台词。

核心约定：

- 同一大章节内按 `Chapter.Sections` 顺序连续播放；大章节结束停止。
- `Current` 为 `Line` 时交音频层播放。无音频的台词仍在列表，音频层可以跳过并提示。
- `Notice` 应显示提示，再由调用方 `MoveNext`。`Choice` 必须 `Choose` 或 `SkipChoice`，不能用 `MoveNext` 绕过。
- `First` 在一处菜单默认选第一条；返回同一菜单后不会重复选择造成死循环。
- `Manual` 对返回的菜单只提供尚未听过的选择，可明确跳过剩余项；未决定路线只截断当前小节，后面小节依然可以明确 `SeekSection`。
- `All` 听取互斥/有条件的不同路线，不尝试模拟游戏条件。共同节点按节点编号去重；文本相同但编号不同的两句保留。
- `All` 将未接入导航的非归档台词追加为“小节补充片段（顺序未核实）”，按包内收录顺序收听，并先显示说明。它们不声称是已核实游戏路线。
- `SeekNode` 只接受当前策略已展开的台词，不暗中更改策略。界面应从 `Items` 的 `Line` 项构建可选台词。
- 所有位置/书签使用独立 `ListeningProgressStore`；音频更新保留位置，剧情或连接改变时尝试按节点编号定位并清除句内时间。
- 存档中为空的显示字段会修复；单条坏书签或坏断点不清空其他有效书签。坏主文件首次重新保存前会按 `.unreadable-时间-随机编号` 留存原件，已有有效 `.bak` 不被坏主文件覆盖；留存失败则保存失败，原件保持不动。
- `TryRestore` 只恢复位置，不播放。音频层读取 `ResumePositionMs` 后负责开始/暂停与实际时长边界。

固定用例覆盖小节衔接、分支汇合、嵌套、人物话题、返回菜单、旧包串排、条件路线、重复文字、补充片段、循环、缺音、归档、毫秒断点、完结、目录跳转、策略切换、更新、存档备份、坏主文件恢复、空字段修复、逐条保留有效书签与损坏原件留存。

不由此工程验证的项目：安卓后台存活、音频焦点、耳机/通知栏控制、真实音频中断及设备耗电，须由安卓适配层和设备测试负责。
